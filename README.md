# Система бронювання — Django

## Запуск

1. Зробити и активувати venv.
2. Скачати залежності:

```bash
pip install -r requirements.txt
```

3. Зробити міграції:

```bash
python manage.py makemigrations
python manage.py migrate
```

4. Створити адміністратора:

```bash
python manage.py createsuperuser
```

5. Запустити:

```bash
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/
Admin: http://127.0.0.1:8000/admin/

## Що зроблено в проекті

- 3 моделі: Room, Profile, Booking + User.
- Django Admin для кімнат, користувачів, профілів і бронювань.
- Реєстрація та вхід.
- Підтвердження email через токен.
- Список кімнат і фільтрація за типом.
- Створення бронювання.
- Перевірка пересечения бронювань.
- Перевірка доступності через AJAX/API без перезавантаження сторінки.
- Список власних бронювань.
- Скасування власного бронювання.
- Календар зайнятих періодів.
- Статуси pending / confirmed / cancelled.
- Розрахунок загальної вартості.

## Email у розробці

У settings.py використовується console email backend. Після реєстрації посилання підтвердження буде виведене в терміналі, де запущено `runserver`.

Для реальної пошти потрібно замінити EMAIL_BACKEND та додати SMTP-параметри.

## PostgreSQL

Для продакшну можна замінити DATABASES на PostgreSQL. SQLite залишено для начальної розробки.
